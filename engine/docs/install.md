# Build Kokiri for Mac

Use the current [Kokiri build guide](../../BUILDING.md) for the native launcher and private game runtime. It documents the supported owned inputs, `engine/build.py`, external work/output paths and explicit full-preparation settings.

The former upstream installation instructions used a different repository layout and entry points. Their build-time, package-size and quick-update estimates do not describe current Kokiri v28 preparation. See [project status](../../STATUS.md) for accepted milestones and remaining limits, and [source provenance](kokiri-source-provenance.md) for the credited runtime lineage.
