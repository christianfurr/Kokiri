# 在 Mac 上构建 Kokiri

请使用当前的 [Kokiri 构建指南（英文）](../../BUILDING.md)。该指南说明原生启动器与私人游戏运行时的区别、所需的自有游戏文件和字体、`engine/build.py` 入口，以及仓库外的工作目录和输出路径。

完整的 v28 着色器准备尚未完成，当前完整构建尚无通过验收的可玩软件包。旧版上游安装文档中的命令、构建时间和软件包大小估计不适用于当前 Kokiri。请查看[项目状态](../../STATUS.md)了解进度和限制。
